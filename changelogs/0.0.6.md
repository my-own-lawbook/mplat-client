## Changelog for release 0.0.6

Release 0.0.6 creates the following changes:

- Made android app name user visible
- Fixed an issue where sync would not delete unused local entities
- Fixed an issue where finishing your profile would not redirect the user to the main app
- Added a dashboard menu-item to logout and delete auth tokens
- Fixed an issue where the profile screen would not validate whether a birthday lied in the future
  or not

- Made the signup, email and profile screen do repeated background-checks for the status of the
  signup-process, so now users can seamlessly perform part of the signup on web and part on the app.

- Added a deep-linking system and set up the deep-link to verify the email address
