## Changelog for release <semver>

Release <semver> creates the following changes:

- Set up the home screen
    - Encapsulates the 'core' functionalities of the app
    - Handles navigation graph and navigation components
- Created placeholder 'profile' and 'dashboard' module

- Set up the database
  - Tables for law books, law sections, law entries, law invitations, foreign users, book <-> member
    crossref
  - Daos for all entities
  - Tests for all daos

- Set up abstraction in data module
  - Repositories for the law books, entries, sections, users and invitations
  - Unit tests for those repositories

- Set up the main overview screen
  - Added use-cases for getting the books and invitations
  - Display feeds on the dashboard screen with books and pending invitations

- Set up the data synchronization
  - Added synchronization logic
  - Added platform-dependant synchronization schedulers (android: work-manager, jvm: kotlin
    coroutines)
  - Added visualising: snackbar when sync failed, loading indicator while syncing
